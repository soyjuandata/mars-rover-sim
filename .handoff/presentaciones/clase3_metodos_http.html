Métodos HTTP

Clase 3 — el vocabulario básico de cualquier API REST

Cuando un cliente (un navegador, un script, una app) habla con un servidor por HTTP, cada pedido incluye un método: un verbo que dice qué tipo de acción se quiere hacer sobre un recurso — algo identificado por una URL, como /libros o /libros/3. Explorá cada método abajo y después probalos en vivo contra una mini API simulada de libros, corriendo enteramente en esta página.
